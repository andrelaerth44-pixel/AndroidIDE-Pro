# UI Guidelines

## Direção

A interface deve parecer uma ferramenta profissional de desenvolvimento.

## Princípios

- Material 3;
- tipografia consistente;
- hierarquia;
- densidade adequada;
- feedback imediato;
- animação funcional;
- adaptação a telas pequenas e grandes.

## Evitar

- neon;
- RGB;
- cyberpunk;
- glow;
- gradientes decorativos;
- excesso de blur;
- glassmorphism como tema inteiro.

## Workspace

Estrutura-alvo:

```
Top Bar
Project / Navigation
Tabs
Editor
Bottom Tool Window
Status
```

Painéis devem ser redimensionáveis quando o tamanho da tela permitir.

## Compose

Compose será preferido em novas superfícies complexas quando reduzir complexidade e melhorar consistência.

Views existentes não serão reescritas apenas por estética.

## Performance

Animações e efeitos não podem causar jank ou consumo desnecessário.
