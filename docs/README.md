## Regra de trabalho

Antes de modificar uma área importante:

1. Ler o módulo.
2. Entender dependências e responsabilidades.
3. Definir impacto.
4. Documentar a decisão quando necessário.
5. Implementar.
6. Registrar a mudança.

O README na raiz continua sendo a visão pública e resumida. Estes arquivos são a memória de engenharia do projeto.
